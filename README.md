# Lotus Specialty Pharmacy

A modern, high-performance website for **Lotus Specialty Pharmacy** featuring custom compounding, comprehensive healthcare services, interactive menus, and rich media showcase.

## Features

- **Custom Lotus Header**: Responsive glassmorphic navigation bar with mega menu dropdowns:
  - **Services**: Free Home Delivery, Immunizations, OTC Card, Patient Consultation, Print Services
  - **Transfer/Refill**: Transfer, Refill
- **Hero Showcase**: High-definition pharmacy exterior showcase with synchronized scrolling card and Lotus branding.
- **About Us Section**: Cinematic pharmacy video promo featuring healthcare consultation and typography with zero drop-shadow clutter.
- **Service Highlights**: Dynamic scrolling gallery representing Lotus Specialty Pharmacy's core healthcare offerings.
- **Full Offline Asset Support**: Embedded high-resolution assets, offline fonts, and optimized media delivery.

## Running Locally

```bash
npm start
# or
node server.js
```

The website will be available at `http://localhost:3000/`.
